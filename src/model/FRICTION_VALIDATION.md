# 합성 마찰 데이터 모델 검증

## 실행

```powershell
Set-Location F:\robot_modeling
.\scripts\validate_friction_models.ps1
```

기본 데이터는 `data/friction_diverse_v1`, 출력은
`result/friction_model_validation_full_v1`이다. 출력 폴더가 이미 있으면
기존 결과를 보호하기 위해 실행이 중단된다. 재실행할 때는
`-OutputRoot result\friction_model_validation_full_v2`처럼 새 경로를 지정한다.

## 데이터와 분할

- 7개 그리퍼·페이로드 조건, 16개 궤적, 조건·궤적당 합성 trial 3개,
  5종 마찰 법칙 × 3강도 = 상태당 15개 토크 라벨을 사용한다.
- Train T1–T11/T15: 상태 988,092행 전부. 각 epoch에서 상태마다 하나의
  마찰 시나리오를 할당하며, 15 epoch 동안 모든 상태가 15개 시나리오를
  한 번씩 학습한다. 학습은 최대 25 epoch다.
- Validation T12: 조건·trial 청크당 고정 난수 128행, 총 2,688개 상태 ×
  15개 시나리오로 모델을 선택한다.
- Test T13/T14/T16: 247,023개 상태 × 15개 시나리오 전부. 학습과
  모델 선택에 사용하지 않는다.
- 모든 모델은 `tau_reference_nm`에 더할 마찰 잔차만 예측한다. 참조 RBD
  토크를 정확히 더하므로 보고한 잔차 RMSE가 합성 총토크 RMSE와 같다.
  실제 로봇 모터 토크의 예측 오차는 아니다.

## 비교 모델

| 모델 | 구성 |
|---|---|
| RBD only | 참조 역동역학 + 마찰 보정 0 |
| Linear | 관절·시나리오별 상수 + `tanh(dq/0.005)` + `dq`의 ridge 회귀 |
| Spline | 관절·시나리오별 속도 1차원 3차 B-spline ridge 회귀, grid 5 |
| MLP | 공유 `28→32→32→6`, SiLU |
| KAN | 공유 spline edge `28→8→6`, grid 5 |

MLP와 KAN은 공통으로 22개 상태 입력(q, dq, ddq, 그리퍼 one-hot,
페이로드 질량)에 마찰 법칙 one-hot 5개와 강도 1개를 더한 28개 입력을
쓴다. 시드 11, 29, 47, Adam 학습률 0.001, batch 2048, 최대 25 epoch,
같은 학습 상태·시나리오 순서와 검증 표본을 사용한다. 파라미터는 각각
2,182개와 2,190개다. Linear의 `0.005`는 데이터 생성 설정에 명시된
평활화 속도를 이용한 물리적 사전 지식이다. 따라서 Linear와 신경망은
동일한 사전 지식을 받은 모델이 아니다.

## 전체 Train 실행 결과

아래는 15개 시나리오와 6개 관절을 동일 비중으로 합친 T13/T14/T16
Test 토크 RMSE다. MLP·KAN은 3개 시드의 평균 ± 표본 표준편차다.

| 모델 | 파라미터 | 학습 시간 | Test RMSE (Nm) |
|---|---:|---:|---:|
| RBD only | 0 | 0 s | 0.28566 |
| Linear | 270 | 0.46 s | 0.06444 |
| Spline | 810 | 1.12 s | 0.06303 |
| MLP | 2,182 | 평균 9.95 s | **0.04563 ± 0.00080** |
| KAN | 2,190 | 평균 121.61 s | 0.07102 ± 0.00062 |

이번 고정 구조와 25 epoch 예산에서는 MLP가 가장 낮은 전체 오차를
보였다. 마찰 보정 없는 RBD 대비 84.0%, Spline 대비 27.6% 낮은
RMSE다. KAN은 MLP보다 오차가 55.7% 높고 학습 시간은 약 12.2배였다.
이 수치로 다른 KAN 구조나 예산까지 일반화할 수는 없다.

마찰 법칙별 Test RMSE를 강도 3개와 신경망 시드 3개에 걸쳐 합치면
다음과 같다. 선형 회귀의 설계식이 생성에 쓰인 평활화 속도 `0.005`
rad/s를 알고 있다는 점을 함께 보아야 한다.

| 합성 마찰 법칙 | Linear | Spline | MLP | KAN |
|---|---:|---:|---:|---:|
| Coulomb | 0.03007 | 0.03883 | 0.02882 | 0.05599 |
| Viscous | 0.00000 | 0.00155 | 0.01335 | 0.01763 |
| Stribeck | 0.00304 | 0.02341 | 0.02144 | 0.05339 |
| Asymmetric | 0.01866 | 0.02059 | 0.01842 | 0.04088 |
| LuGre형 | 0.13964 | 0.13183 | **0.09275** | 0.13136 |

MLP의 전체 이점은 주로 이력 의존 LuGre형 라벨에서 나온다. 다만
MLP도 그 법칙의 내부 이력을 입력으로 받지 않으므로 정확한 동적
마찰 식별이라고 해석할 수 없다. Viscous와 Stribeck에서는 사전
지식을 반영한 Linear가 더 정확하다. MLP의 7조건 Test RMSE 평균은
0.04559–0.04567 Nm로 거의 같다. 이 합성 데이터만으로 그리퍼별로
다른 마찰 구조가 존재한다는 결론을 낼 수 없다.

## 범위와 주의사항

이것은 **오프라인 합성 마찰 라벨에 대한 궤적 분할 검증**이다. 세 trial은
실로봇 반복 실험이 아니라 시드가 다른 궤적 변형이다. LuGre형 라벨은
이전 속도에 따른 내부 상태가 있는데, 비교 모델의 28개 입력에는 그
이력이 직접 들어 있지 않다. 모든 마찰 법칙·강도·그리퍼·페이로드
조건이 학습에 등장했으므로, 미학습 법칙이나 미학습 페이로드로의
일반화는 검증하지 않는다. 기존 J1 21회 마찰 보상 예비 실험과도 별개다.
같은 궤적·trial의 7조건은 q, dq, ddq가 같아 통계적으로 독립적인
동작 7개가 아니다. 네 개의 명시적 합성 마찰 법칙 라벨은 그 조건들에서
같고, Coulomb 라벨만 장면의 역동역학에 따라 달라질 수 있다.

앞서 같은 Test 궤적에 대해 상태 청크당 256행만 학습한 탐색 실행을
`result/friction_model_validation_v1`에 저장했다. 그 뒤 전체 Train을
사용하는 실행을 추가했다. 따라서 이 Test는 완전히 독립적인 후속 확인
세트로 간주할 수 없으며, 이 문서의 결과는 탐색적 비교로 해석한다.

`overall.csv`, `by_scenario.csv`, `by_condition.csv`, `by_joint.csv`,
`history.csv`, `summary.json`, 체크포인트와 그래프가 결과 폴더에 저장된다.
Train 표본·속도 구간·KAN 함수·LuGre 이력 입력·KAN 설정에 대한 후속
분해는 [FRICTION_DIAGNOSTICS.md](FRICTION_DIAGNOSTICS.md)에 있다.
