# 합성 마찰 모델 성능 차이 진단

이 문서는 `data/friction_diverse_v1`와 기존
`result/friction_model_validation_full_v1` 체크포인트를 사용한다. 기존
학습 결과와 데이터는 수정하지 않았다. 새 KAN 설정 실험은 T12 검증에서만
비교한다. 원본 Test NPZ는 열지 않고 기존 결과 CSV에서는 T12 행만
사용한다.

```powershell
Set-Location F:\robot_modeling
.\scripts\diagnose_friction_models.ps1 -Mode Audit
.\scripts\diagnose_friction_models.ps1 -Mode History
.\scripts\diagnose_friction_models.ps1 -Mode Sensitivity
```

각 실행은 시각이 붙은 새 `result` 폴더를 만들어 기존 결과를 보호한다.
`-Mode All`로 세 진단을 순서대로 실행할 수도 있다.

## 기존 모델의 분해 결과

| 모델 | Train 표본 RMSE | T12 Validation RMSE | T13/T14/T16 Test RMSE |
|---|---:|---:|---:|
| MLP, 3시드 평균 | 0.04465 | 0.05192 | 0.04563 |
| KAN, 3시드 평균 | 0.07575 | 0.06889 | 0.07102 |

단위는 Nm이다. Train 표본은 각 조건·궤적·trial 청크에서 64개씩
고정 시드로 뽑은 16,128개 상태이며, 모두 원래 학습에 포함됐다.
같은 궤적·trial의 7조건은 관절 운동이 같으므로 독립적인 16,128개
운동으로 간주하지 않는다.
Validation은 기존 실험의 2,688개 상태, Test는 기존 실험의 247,023개
상태다. KAN은 학습에 사용한 상태에서도 MLP보다 오차가 커서,
**Test에만 나타나는 일반화 실패라는 설명은 맞지 않는다.**
학습 예산·최적화 또는 구조적 제약의 상대적 영향을 이 숫자만으로
분리할 수는 없다.

| 마찰 법칙 | MLP Test RMSE | KAN Test RMSE |
|---|---:|---:|
| Coulomb | 0.02882 | 0.05599 |
| Viscous | 0.01335 | 0.01763 |
| Stribeck | 0.02144 | 0.05339 |
| Asymmetric | 0.01842 | 0.04088 |
| LuGre형 | 0.09275 | 0.13136 |
| **LuGre형 제외** | **0.02123** | **0.04462** |

MLP는 다섯 유형 모두에서 이 설정의 KAN보다 정확하다. LuGre형은
두 모델의 **제곱오차 차이 중 58.4%**를 차지하지만 유일한 원인은
아니다. 관절별 제곱오차 차이의 45.2%는 J1, 24.3%는 J2, 19.2%는
J3에서 나온다. 각 조건별 출력은 기존 `by_condition.csv`에 있다.

추가 T12 표본에서 속도 절댓값이 0.005 rad/s 미만인 구간의 RMSE는
Stribeck에서 MLP 0.0220 / KAN 0.0474 Nm, LuGre형에서 MLP 0.1470 /
KAN 0.2008 Nm다. 이 구간의 관절×시나리오 요소는 각 유형당 10,671개다.
이 수치는 별도로 추출한 T12 표본의 진단값이며 기존 전체 Test 점수가
아니다.

## KAN 함수와 격자

현재 KAN의 첫 층은 각 입력에서 8개 숨은 노드로 향하는 3차 spline
edge를 갖는다. J1 속도 edge 중에는 0 부근에서 부호가 급변하는
형상이 나타난다. 그러나 개별 edge의 출력은 숨은 표현이며 관절 토크나
그리퍼별 물리 파라미터로 바로 해석할 수 없다. 조건별 일관된 함수
변화나 지속학습 이점은 아직 입증되지 않았다.

grid 5의 J1 중심 격자 간격은 정규화된 속도를 원래 단위로 환산하면
약 0.0169 rad/s다. 생성된 Stribeck의 평활화 속도는 0.005 rad/s다.
격자가 전이 구간에 거칠 수 있다는 **가설**을 뒷받침하지만,
Spline 조합으로 전이를 근사할 수도 있으므로 이것만 원인으로
확정하지 않는다. J1 학습 표본에서 정규화 속도 `|z|>2` 비율은 5.5%다.
`j1_partial_dependence.png`는 20개 학습 맥락에서 J1 속도만 바꾼
조건부 곡선이다. 이 곡선은 일부 입력 조합이 실제 궤적 밖에 있을 수
있으므로 Test RMSE의 대용으로 쓰지 않는다.

## KAN 설정 민감도: T12만 사용

동일한 전체 Train과 시드 11에서 KAN의 격자·폭·학습률·epoch를
하나씩 바꿨다. 기존 실험에서 사용한 T12의 **같은 2,688개 상태**를
재현해 모델을 선택했다. 원본 Test NPZ를 읽거나 변형 모델의 Test
점수를 계산하지 않았다.

| KAN 설정 | 파라미터 | 최적 epoch | T12 RMSE (Nm) |
|---|---:|---:|---:|
| 원래 grid 5, 폭 8, 최대 25 epoch, lr 0.001 | 2,190 | 24 | 0.06853 |
| grid 9, 폭 8 | 3,278 | 11 | 0.06846 |
| grid 5, 폭 16 | 4,374 | 25 | **0.06515** |
| grid 5, 폭 8, 최대 50 epoch | 2,190 | 45 | 0.06701 |
| grid 5, 폭 8, lr 0.003 | 2,190 | 23 | 0.06931 |

참고로 기존 MLP 시드 11의 같은 T12 RMSE는 0.05131 Nm다. 폭과
학습 시간을 늘리면 KAN이 조금 나아지지만, 시도한 설정에서는
MLP 수준에 이르지 못했다. grid 간격만 늘리는 조치는 거의 효과가
없었다. 이 실험은 **한 시드의 제한된 탐색**이고 변형마다 파라미터 수와
학습 예산이 달라, KAN 계열 전체의 최적 구조나 성능 상한을 결정하지
않는다. 이 설정으로 Test 성능을 주장하지 않는다.

## LuGre형 이력 입력 실험

10 Hz 데이터에서 현재 속도에 과거 0.1, 0.2, 0.5, 1, 2초 속도를
추가한 관절별 ridge 회귀를 만들었다. 비교 대상은 현재 속도만의
회귀와 **같은 234개 파라미터**를 갖는 현재 속도 Spline이다.
학습은 bare 조건 T1–T11/T15, 검증은 bare 조건 T12의 합성 trial 3개다.
각 청크 첫 2초는 과거 입력을 완전히 확보할 수 없어 세 모델에서
동일하게 제외했다. Test는 사용하지 않았다.

| LuGre형 모델 | 파라미터 | T12 RMSE (Nm) |
|---|---:|---:|
| 현재 속도 선형 | 54 | 0.13884 |
| 현재 속도 Spline | 234 | 0.13109 |
| 현재 + 과거 속도 회귀 | 234 | **0.06931** |

같은 파라미터 수의 Spline 대비 이력 입력의 RMSE가 47.1% 낮다.
세 개의 합성 검증 trial에서도 각각 개선됐다.
따라서 **이 합성 LuGre형 라벨에는 과거 운동 정보가 실질적으로
유용하다.** 이 결과만으로 실제 로봇의 LuGre 내부 상태를 식별했다거나
MLP와 KAN의 성능 차이를 전부 이력 부족으로 설명할 수는 없다.

## 해석 범위

- H1의 “KAN 보정이 RBD보다 정확하다”는 이 합성 마찰 설정에서
  지지된다. “KAN이 MLP보다 정확하고 효율적이다”는 지지되지 않는다.
- 현재 KAN의 물리적 함수 해석 가능성은 edge 그림 한 장으로 입증할 수
  없고, 조건별 함수 안정성·개입 검증이 필요하다.
- H2의 지속학습·망각 감소는 이 실험에서 평가하지 않았다.
- 합성 trial 3개는 독립적인 실로봇 반복 실험이 아니다. 원래 Test를
  탐색 과정에서 이미 확인했으므로 본 분석은 확증 결과가 아니다.

세부 CSV와 PNG/SVG는
`result/friction_model_diagnostics_v2`,
`result/friction_history_diagnostic_v2`,
`result/friction_kan_sensitivity_v1`에 저장한다.
